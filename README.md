# College Trip Registration Website

This website is created for **Central University of Rajasthan** to allow students to register for upcoming trips. Interested students can fill out the form, and their data will be stored securely in **MySQL**.

## Features
- Student registration form
- Data storage in MySQL
- User-friendly interface
